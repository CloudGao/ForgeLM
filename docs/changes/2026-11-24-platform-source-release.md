# 仅发布平台系统

本次当前文件树的发布边界为平台控制面、Web、Worker、core、SDK 与通用示例。模型结构、训练实现、权重、数据、私人实验配置不进入当前发布树。沿用原仓库并保留旧提交，维护者接受历史中的 MicroLM 源码仍可访问；无需重写历史或更换仓库地址。

## 现有能力与修改

复用已有 Git/本地目录/归档代码导入、不可变代码版本、用户命令适配器和 `.flsuite` 机制，不新增 Git 托管或模型调度系统。

- 主 Python 包不打包模型源码；公开目录不包含 MicroLM 模型套件。
- 普通远程部署 release 不读取模型 requirements，不上传模型依赖文件。
- WSL/远程引导移除 MicroLM 专属安装预设；默认插件目录移除内置 MicroLM 套件与量化组件。
- 旧格式兼容桥仅调用外部已安装运行时，不自动搜索邻近的私有模型目录。
- 私有模型训练循环对应的 SFT 批量融合实现与专属测试不在发布范围内。
- 平台与 SDK 使用 Apache-2.0；记录 Python/Web 依赖许可，Web 构建随附原许可文本。

## 干净环境验证发现并修复的问题

- 测试原先共享会话数据库，残留任务、制品与 Worker 会污染其他测试。现在逐测试清理专用临时数据库，保持真实迁移后的 Schema；每个 TestClient 管理自己的生命周期。
- 存储清理原来使用 Python 3.12 专属 `rmtree(onexc=...)`；改用 Python 3.11 兼容回调，保留已校验路径和只读文件重试约束。
- SDK 构建移除对宿主预装构建工具的隐式依赖，使用标准构建隔离。
- 更新过时的测试输入与界面定位，不放松业务预检；未安装的可选运行时明确跳过。
- Windows 安装脚本检查原生命令退出码，失败时不会打印安装成功。

## 架构与验证

控制面、任务调度、项目与版本归属、制品血缘和套件协议保持。模型开发仓库与平台执行版本各司其职。验证结果及未验证项见 [发布检查](../RELEASE_CHECK.md)。
