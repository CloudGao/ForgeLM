# ForgeLM 独立仓库发布

## 范围与实施

维护者确认将已清理的平台作为独立 ForgeLM 仓库维护，本地开发目录继续使用。以已通过 Windows/Linux、Python 3.11/3.12 CI 的实现代码为基础，完善 README、保留 Apache-2.0 与第三方许可证声明。

迁移前保存完整旧 Git 元数据、文件清单和校验值。新仓库仅提交已审查的平台文件，建立独立初始提交，不导入旧仓库历史；原远端保留作为存档。新仓库推送验证后，将本地 Git 元数据接入新 main，origin 指向 CloudGao/ForgeLM。模型源码、权重、运行数据库及本地配置保持原路径，不加入发布提交。

## 架构与验证

不修改平台业务、执行机制或存储结构，不重启服务。新仓库需要独立通过 CI；迁移前验证不冒充迁移后结果。核对初始提交没有父提交、发布文件边界、远端地址、分支跟踪和工作目录状态。README 提供项目定位、能力表、架构图、安装步骤、扩展入口与安全边界。
