# ForgeLM 产品设计

## 定位

ForgeLM 是本地优先、可信单用户使用的大模型生命周期控制与追踪平台。公开仓库发布平台系统，不发布模型结构、训练算法实现、权重、训练语料或私人实验记录。

平台管理数据与模型代码的不可变版本、Tokenizer、训练实例、任务、Checkpoint、评测、量化、交付和推理请求；实际算法由用户代码、外部运行时或受信任插件执行。

## 代码与模型的边界

- 模型开发源码由独立 Git 仓库或本地目录管理；平台不提供 Git 托管、分支编辑或代码合并服务。
- 平台已有 Git、本地目录、归档和浏览器上传的代码导入入口。导入后生成不可变代码版本及代码制品，训练配置绑定版本，任务冻结实际执行输入。
- 模型代码版本、训练 Checkpoint 和模型版本是不同对象。代码版本描述执行程序，Checkpoint 描述训练状态，模型版本描述登记的模型输出及其元数据。
- 导入代码不会自动安装任意依赖。依赖由执行环境管理员准备，或通过现有 `.flsuite` 套件的依赖锁与隔离安装流程提供。
- 此源码发布不含 MicroLM 模型实现或套件，也不提供 MicroLM 专属安装配置。保留的旧格式兼容适配器仅能调用另行安装的外部运行时，不代表平台包含该模型。

## 主要流程

1. 登记、导入和分析数据，创建不可变版本；项目通过绑定消费全局资产。
2. 按现有转换、清洗、混合与监督数据准备入口形成数据血缘。
3. 导入模型代码或安装受信任套件，准备真实 Worker 环境。
4. 创建训练实例与可执行 DAG，冻结配置、输入版本和执行参数后提交。
5. Worker 领取任务，执行引擎，回传日志、指标、状态与产物。
6. 通过模型登记、评测、量化与发布入口消费产物，并保留来源关系。

## 已有通用能力

- 项目中心、全局数据目录、模型权重目录、项目资产绑定。
- 文本/结构化数据导入，PDF/DOCX/EPUB 转换，Data-Juicer 可选清洗适配器，数据混合、预览与检索。
- Hugging Face Tokenizers 训练适配器，Tokenized Corpus 与 Training Data View。
- 不可变训练实例、DAG、任务尝试、资源租约、日志、指标与制品登记。
- 结构化用户命令适配器、可安装套件、SDK、插件任务与服务协议。
- Transformers 推理、lm-evaluation-harness 评测、LLM Compressor 量化的外部运行时接入。
- Windows 本机、WSL、远程 Linux Worker 管理；远程 Worker 支持基础、数据处理和 HF 推理配置。
- SSH 引导、节点凭据、Agent 隧道、显式数据物化、存储盘点及受约束清理。

接口存在不代表对应外部引擎已经安装或任意模型可运行。界面与执行记录应区分平台契约、Worker 声明、预检结果和实际完成结果。

## 安全与能力限制

- 无内置用户、角色或项目级访问控制，不能直接作为公网服务或多租户服务部署。
- 插件虚拟环境用于依赖隔离，不是安全沙箱。用户代码以 Worker 操作系统账户权限运行。
- 只有本地进程 Launcher；未提供内置 Slurm、Kubernetes 或多机 Rendezvous Launcher。
- SQLite 控制面按单实例运行，不支持多个控制面共享写入。
- 暂停、恢复、优化器状态接续与训练性能比较取决于引擎明确声明并实现的契约；平台不内置一个通用训练算法。
- 模型与数据许可由其各自来源决定，平台不会自动接受 gated 模型条款或替用户授予分发权。
